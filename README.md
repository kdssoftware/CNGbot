# EVE Mail and Role Discord Bot

Install this Discord bot on your Discord server at [discord.com/discovery/applications/1537081375503425706](https://discord.com/discovery/applications/1537081375503425706).
To setup type the `/dasboard` command

This Go based Discord bot polls the EVE Online ESI API for new in game EVE Mail and forwards it to a specific Discord channel while mapping EVE characters to Discord users. The bot also manages Discord roles by mapping EVE Corporation and Alliance IDs to Discord roles, automatically removing roles if characters leave their mapped organizations.

## Benefits

* **Stay Connected:** Read your important EVE mail directly within your Discord server without needing to log into the game.
* **Effortless Role Management:** Keep your server secure and accurate. The bot handles role assignments and removals automatically based on corporation or alliance membership.
* **Instant Notifications:** Get pinged directly when you receive mail in game.
* **Seamless Operations:** With database support and automatic mapping, your leadership team spends less time auditing users and more time playing the game.

## Features

The CNG Bot offers a variety of capabilities that can significantly benefit an EVE Online server community.

### Automated Role Synchronization
The bot automatically synchronizes Discord roles with EVE Online characters, corporations, and alliances. When members join or leave groups in the game, their Discord roles are updated accordingly.

### EVE Mail Forwarding
Important in game messages and alliance updates sent via EVE Mail can be automatically forwarded to a designated Discord channel. This ensures members stay informed without needing to log into the game.

### Standings Management
Corporation and alliance standings can be mapped to Discord roles. This allows community leaders to easily organize allies, neutral entities, and adversaries within their server.

### Event Tracking
The bot can monitor and post newly created in game calendar events to Discord, helping fleets and operations stay organized.

### Security and Authentication
The bot supports Two Factor Authentication checks for granting roles, ensuring that only verified users gain access to sensitive server areas. It also integrates with SeAT to enforce registration requirements.
